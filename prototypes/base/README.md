## C12 形态确认（2026-08-26）

用户逐屏走查 `prototypes/codegraph-two-axis/`（C12 的 fork 副本）完毕，**这次确认的形态
就是最终验收基准**——真实页面开发完成后对照它验收，不另起标准。走查裁决全文在
`docs/specs/2026-08-25-codegraph-viewer-two-axis-spec.md`，逐轮留痕在卡 C12 的 timeline。

确认到的形态要点：

- **结构轴一个页面按 scope 变**：根（12 个顶层领域 = 子系统）→ 领域 → 容器（叶子领域，
  按包聚成群组）。子系统就是顶层领域，「进领域」不是单独动作。**容器是原子节点，没有详情页。**
- **右栏三 tab**：基本信息 · 对外面 · 状态机；分隔条可拖。
- **行为轴入口流程图**：矩形调用 / 菱形分支 / 卫语句甩到一侧 / 分支体缩进成子干；
  **蛇形折列**（第 1 列自上而下从底部接进第 2 列，第 2 列自下而上从顶部接进第 3 列）；
  紫框 ▸ 是下层入口可递归下钻；**双线框是接口调用——图上展示接口，右栏列全部实现，
  每个实现的入口就是那个实现的流程图起点**。
- **降级一律显式**：数据缺失的格位要说清缺什么，不显示看起来完整的假读数。

fork 副本 `prototypes/codegraph-two-axis/` 不入库，回流合并进 `base/` 由
`charter:finish` 在收尾时执行。确认基准已落在本文件，副本删除也不会丢。
