## 导航模型（2026-08-25 用户逐屏走查后定稿）

**一个页面，变的只有 scope。**「进领域」不是一个单独动作——子系统就是顶层领域，双击一路下去就是。

```
index.html?scope=              →  12 个顶层领域（= 子系统）
index.html?scope=d_execution   →  它的 3 个下层领域
index.html?scope=d_ledger      →  它的 12 个容器（叶子领域，到此为止）

  单击 ─▶ 右栏三个 tab：基本信息 · 对外面 · 状态机（分隔条可拖）
  双击 ─▶ 领域换 scope；容器没有下一层（原子节点，双击无动作）
  右栏「程序入口」点进去 ─▶ pages/behav-flow.html（流程图，递归下钻）
```

**已删除的页面**：

- `struct-subsystems.html` / `struct-inside.html` / `struct-domain.html`——对 9 个叶子子系统
  画的是同一批容器，是重复；三页合并成 `index.html` 一个按 scope 变的页面。
- `struct-container.html`（容器详情页）——容器的职责已经在图上、也在右栏「基本信息」，
  剩下只有符号清单；按「真正的调用链给 agent 看，不给人看」的裁决，那份清单对人没有价值。
  **容器是原子节点，没有详情页**。

## 术语（界面上不得混用）

| 词 | 定义 | 在哪 |
|---|---|---|
| **程序入口** | CLI / HTTP / WS，系统的外部入口（162 个） | 右栏「基本信息」底部；点它进流程图 |
| **对外入缝** | 跨这一层边界被调进来的符号，这一层的契约面 | 右栏「对外面」tab |
| **泳道** | 流程图的一条：一条程序入口一条 | 流程图页，不在 scope 页 |
| **接口调用** | 被调者是接口方法的调用点（双线框） | 流程图页；右栏列全部实现 |

## 行为轴（2026-08-26 走查定稿）

`pages/behav-flow.html?e=<入口>`。一条主干竖着走：矩形 = 调用（左侧色条 = 领域），
菱形 = 分支，卫语句甩到右侧返回终点，分支体缩进成子干并留一条「否」旁路绕回。

- **折列不滚动**：装不下就折成下一列（列数由画布宽度算出，拖分隔条会重排），
  列间画一条**蛇形连线**（往下 → 拐进走廊往上 → 拐进下一列开头），不用文字标签代替线。
- **紫框 ▸**：该节点本身是下层入口 → 点进去是它自己的流程图（递归下钻）。
- **双线框**：接口调用 → 图上展示**接口**（代码里写的就是它，走到哪个实现是运行期的事），
  右栏列全部实现，**每个实现的入口就是那个实现的流程图起点**。
- 右栏三 tab：基本信息 · 复用与抽象债 · 调用链（给 agent）。

三条流程是**手抽自真实源码**的（`shared/flowmock.js`，每步带行号可逐行核对），用来定形态：

| 入口 | 演示什么 |
|---|---|
| `handoff card dispatch` | 分支/卫语句/递归下钻；四条复用与抽象债读数 |
| `POST /api/tasks → Manager.Dispatch` | 蛇形折列；**接口 → 实现**；承重摘要 |
| `claudecode.Adapter.Start` | 实现的流程图（下钻落点），回链到接口那一层 |

## 布局判据

- 方向靠**箭头**表达，不靠节点排在第几层。
- 摆放两条：能看见全部节点时**空白最少**、**交叉最少**（连接权重贪心排序 → 货架装箱，目标长宽比
  贴合实际画布 → 相邻交换降交叉）。
- 分层只用于节点本身就是聚合单位的层（根层、中间领域层）；**孤立节点不进分层图**。
- 容器层按**包**聚成群组，边接到具体容器（40 容器 → 6 包）。
- 画布：空白拖动平移，⌘/Ctrl + 滚轮缩放，双击空白复位。

## 已知的降级格位（界面上都有显式标注）

1. **流程图的数据**：`baseline` 里没有控制流（无次序、无分支），所以三条流程是手抽的样板；
   其余入口一律显示空态，**不拿机械可达序列冒充流程图**——那份序列改放右栏「调用链（给 agent）」
   tab，如实标注它没有次序也没有分支。等 roadmap 27/32。
   **递归下钻只做到两跳**，接口四个实现只手抽了 claudecode 一条，其余标「原型未抽」。
2. **领域声明**：23 个域只有 2 个有声明，不变式/状态机大面积空态。等 roadmap 1a。
3. **包摘要**：这份 baseline 没有 `packages` 段（B231 之后才有的键），群组框只有包名和容器数。
