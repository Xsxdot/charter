# charter

以用户故事验证结果、按子系统保持代码责任、让 Agent 的自主决定对人可见的开发流程套件。流程中的每个节点是一个 skill：Claude Code 插件——SessionStart hook 注入网关 `using-charter`，节点 skill 按需加载，subagent 跑流程时逐节点注入纪律。进流程的请求**一律建卡**，L1 也不例外（2026-10-20 用户定，撤销 10-18「账本可选」）。

## 结构

入口只有两条（网关直接分流，无分诊节点）：bug → implement（排查节）；需求/想法 → spec（定级与选档在 spec 收尾定稿）。

```
skills/
├── using-charter/     # 网关（hook 注入）：节点地图 + 交回物纪律（唯一副本）+ 红旗
├── spec/              # 需求成形：承重歧义 + 承诺清单 + 对话纪律 + 定级 + 边界与接缝语义三行（L3）
├── plan/              # 实现计划：零上下文交接五件事 + 决策权限 + 真机清单（含首跑项）；L3 的拆分、层表 + 可编译骨架 + 楼层图（五判据）、契约面冻结 = 骨架
├── implement/         # 实现：两层测试（故事级检查 + 不变式单测）、只测当前组件 + 骨架边界 + 真机前移 + 三段律 + 日志注释 + 熔断 + 排查节（bug 入口）
├── review/            # 审查与验收：首核「偏离与自主决定」+ 双轴（含越界、缺陷族三问格）+ 复跑 → 变异 → 真机 + 批级验收（一次全量 + 整体走查）；L1 主会话单审一轮
├── finish/            # 收尾：两级——卡级合入集成分支、批级一次全量后 main ff-only；核验收 + 合并归人 + 原型基准回流 + 残余落账
└── architecture-law/  # 架构法·子系统与领域章（法条 + 判据数字，零案例）——参考法：spec / plan / review 按需查阅，不自动注入纪律块
scripts/               # regen_discipline（正文 → 节点纪律正文，供外部种子脚本消费）
docs/                  # specs / plans / reviews / roadmap（残余账本）；ledgers 为历史目录，第三步起不再新建台账文件
```

## 术语（两级）

- **子系统**：并行协作与契约冻结的单元——只以契约面对外、独立生命周期、有消费者（判据见架构法第一条）。L3 = 新增或变更跨子系统的契约面（或对接既有跨仓/跨进程 wire 契约）；跨子系统各改内部不是 L3，是多张 L2 挂集成父卡。内部有几个领域与它是不是子系统无关。
- **领域**：子系统内部按业务概念聚合的模块；长大后可升格为嵌套子系统（递归，上限 3 级）。

## 设计原则

- **两个目标，各有唯一承载**：架构干净 → spec 的 L3 边界三行 + review「越界」格（`architecture-law` 为按需参考法）；注意力集中 → plan 的「决策权限」+ 交回物首节「偏离与自主决定」。其余条款都为这两条服务，服务不上的删。节点只有五个，门只有两道（implement 要 plan 附件、finish 要子卡完结）。
- **规则与知识分离**：本仓库只装不变的纪律与法条；项目知识（子系统划分、契约面、缺陷史）活在各项目仓库的架构文档与领域文档里。
- **法条零案例**：判据数字即先例（≥5 文件、≥40 文件、≥20 方法、3 级嵌套），不引任何真实项目路径。
- **凡红线必留正当出口**：每条禁令配显式例外，防红线诱发绕过。
- **判决一次、时刻正确**：定级不设分诊节点——在 spec 定稿、信息足够时只判一次；判错走跨流迁移，带产出走。
- **并行按依赖图**：L3 先由可编译骨架合入集成分支立共同基线，子卡按依赖图分批；契约面冻结由骨架承载、编译核对，文字只留跨仓/跨进程 wire 承诺与拍板记录。
- **信息归唯一载体**：判决与状态 → 产物头部状态行；残余 → `docs/roadmap.md`；读数与证据 → 产出物末节「读数与证据」（不再建独立台账文件）；欠账 → 交棒声明；交回物纪律正文只在网关一处，纪律块只含各节点正文、不带附录。
- **修法两件事**：每笔 `skills/` 正文变更须①授权留痕（卡/spec，或用户显式指令原话入提交说明）②`python3 scripts/regen_discipline.py --out <临时目录>` 仍产出五节点正文（外部种子脚本消费）。
