### 实现步骤

1. 先在 assemble_test.go、source_test.go、query_test.go 写失败的声明缝测试，执行 go test ./codegraph -run 'Test(AssembleResult|ExtractSourceWindow|NeighborhoodSkipsDeletedOutputEdges|RefSnippetWireRemoval)' -count=1。新符号缺失的编译红后，补空壳并再次确认有默认投影、source、budget 或 deleted-edge 的断言红；编译红不能代替行为红。

2. 在 assemble.go 放置完整类型块。四个固定常量各写同处注释：shared-util 3 对应基线 K≥3 命中 28、K≥2 多收 117、K≥4 仅 7；external representatives 3 用于辨认职责而不复刻清单；context depth 3 对齐 C1.10；focus quota 5 以跨域入边排序控制焦点体积。文件头明确装配只发生在 raw BFS 之后，不改 BFS、不写 baseline。

3. 默认投影只保留 id/dist/kind/name/file/line/signature/summary/status/domain；domain 只取 v.Containers[n.Container].Domain，缺容器/空领域/旧图均为空串。Full=true 恢复旧 Node 字段，唯一例外是 Snippet；Full 不关闭 source 或 budget。AssembleResult 必须消费同一次 Neighborhood 结果，不能重载图或重跑 BFS。

4. AssembledItem.MarshalJSON 只接受恰好一个非 nil 指针：普通节点直接编码节点对象，外部项直接编码 domain/count/representatives；零指针和双指针返回带上下文错误。用 json.RawMessage roundtrip 逐键断言 source、truncated、sharedBy:0 的缺失和非零值。

5. 折叠实现顺序固定为先 shared utility、后 external domain。shared utility 按当前视图 live caller 的不同非空领域计数，达到 3 即设置 sharedBy，model 也可命中。external 只折叠 focus domain 之外且有领域的节点，count 为 raw 全量，representatives 按本次结果 live 入边数降序、id 升序取 3，组按 domain 升序。用 live 路径判断：只有所有 raw focus 到下游的路径都经过已收桩/已折叠节点才省略；另一路未收桩可达则保留。普通输出边必须两端都是 live 普通 item，deleted edge 和 deleted endpoint 均过滤。

6. source.go 使用 os.ReadFile + strings.Split；AssembleResult 内按文件缓存行数组，并以 ReAnchor 的行号提取窗口。span 只接受 1..200，负 maxTokens 返回错误，0 不限。file missing、unscanned、空文件、无 file 不伪造 source，保留节点状态并记录结构化 warning；文件存在但 vanished 仍按原始/锚定行取可用窗口。成功记录 file/line/span/lineCount，错误记录 file/line/status/error。

7. token budget 按 raw dist 升序、同距 id 升序加入 item，fold item 用组内最小 dist。每加一项用 compact JSON UTF-8 bytes/3 计算，method 固定 utf8-json-bytes/3、approximate=true；超预算立即停止。atDepth 是第一个未填充 raw 节点 dist，droppedNodes 是未进入输出的 raw 节点数，reason 固定 max-tokens；无截断省略 truncated。记录预算输入和输出规模。

8. query.go 只在 Result.Edges 收集处跳过 e.Status=="deleted"、deleted endpoint；不改 BFS/距离/排序。query_test.go 从 Neighborhood 入口断言 branch-x 结果没有 deleted edge。types.go 删除 Snippet；用旧 JSON 反序列化断言 snippet 被忽略，用新 JSON 编码断言无该键。

9. 跑绿、编译和变异：

~~~bash
gofmt -w codegraph/assemble.go codegraph/assemble_test.go codegraph/source.go codegraph/source_test.go codegraph/query.go codegraph/query_test.go codegraph/types.go
go test ./codegraph -run 'Test(AssembleResult|ExtractSourceWindow|NeighborhoodSkipsDeletedOutputEdges|RefSnippetWireRemoval)' -count=1
go build ./...
~~~

断言矩阵必须包含：默认十字段、Full 字段恢复且无 snippet、外部 count/代表排序、不同领域阈值 3、共享节点唯一 item、deleted edge、span 1/40/200 和首尾收缩、missing/unscanned/empty 状态、UTF-8 预算元数据、truncated 细节、缺失与零值的 JSON 区别。四个变异必须先确认唯一命中并让相关测试转红：阈值改 2、删除 deleted 过滤、Full 关闭 source、droppedNodes 改成输出节点数；编译失败的变异不计数，恢复后再跑绿。

Task A 范围、日志、接缝：只跑 graph/codegraph 新测试和 query 触及测试；收尾跑 go build ./...，不跑全量测试。测试入口为 Neighborhood→AssembleResult、ExtractSourceWindow 和 Neighborhood；非法 AssembledItem union 仅作附加内部锁，因为公开装配无法构造非法 union，不能替代端到端 roundtrip。A 是逻辑型 task，无写路径、进程或权限门。
