## 问题陈述

C14 把分层/卡面读数对齐了 fork 原型，但还有两处和原型（及用户当下观感）不一致：

1. **箭头接到卡片中心**。`ScopeCanvas` 用卡片几何中心当 SVG path 端点；HTML 卡叠在 SVG 之上，箭头头埋在卡面里看不见。原型 `graph.js:54-64` 正向边从源卡下沿中点接到目标卡上沿中点，回边接左右沿中点，同层边接下沿。
2. **未选中时全部半透明**。`renderCard` 在「非选中且非邻居」分支无条件加 `opacity-50` + `data-dimmed`，空选中态下每张卡都被压暗。原型只有 `sel` 有值时才压暗无关项。

## 方案

**选定：只改端点与选中压暗，布局间距不动。**

- 箭头：按边形态接到卡片边框（正向：下沿→上沿；回边：右沿→右沿；同层：下沿→下沿），`GAP_Y=160` 等 C14 间距一律保留。
- 压暗：默认全不透明。点击某张卡后，与它没有边关系的卡（及无关边）才加透明；邻居与自身保持不透明。再点同一张卡取消选中，全场回到不透明。点另一张卡则改选。

弃选：把间距改回原型 `GAPY=92`（用户明确保留当前间距）；空选中也保持半透明当「底图」（与用户「默认全都不是透明的」直接冲突）。

## 用户故事

1. 作为看图的人，我看见箭头头落在卡片边框上，不被卡面盖住，卡片之间的空隙保持现在这样。
2. 作为看图的人，刚打开图画时所有卡片都是实色；点一张卡，只有跟它没关系的才变淡；再点这张卡，恢复全实色。

## 实现决定

1. 端点计算收在 `scopelayout` 纯函数（与 `scopeEdgePath` 同层），画布只消费，不在 JSX 里手算。
2. 压暗条件改为「有选中 ∧ 非自身 ∧ 非邻居」；点击已选中卡时 `onSelect('')` 清空。
3. 无关边在有选中时同样压暗（原型 `dimE`），让「谁跟它有关系」一眼能看出来。
4. 不动 wire、不动布局算法、不动行为轴流程图。

## 测试决定（接缝清单）

- **缝 1：`scopelayout.scopeEdgeAnchors`**（新建导出，调用方 `ScopeCanvas`）——三种形态端点落在源/目标矩形边框，不落中心。
- **缝 2：`ScopeCanvas` 选中投影**（现状调用方 `TwoAxisPage`）——空选中零 `data-dimmed`；有选中时无关项才 `data-dimmed`；再点已选中卡 `onSelect('')`。
